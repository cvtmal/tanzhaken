# Language and time on screen (S7)

- English only, `default_locale: en`, ICU catalogues (`+intl-icu`).
- `messages` holds layout strings (owned by #2). Each module has its own domain, the lower-case module name: `translations/<domain>+intl-icu.en.yaml` (`account`, `students`, `courses`, `credits`, `attendance`, `checkin`, `dashboard`).
- No user-facing string in Twig or PHP outside a catalogue.
- Dates and times print with the intl Twig filters, in the course's timezone for lessons and the teacher's timezone elsewhere; show the zone where it could be unclear.
