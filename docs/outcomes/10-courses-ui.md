# #10 courses-ui — outcome (2026-11-11)

## Delivered
The teacher's course pages behind #4's login. `/courses` lists the active courses as cards (weekday and time tile, students, location, "Today" / "Starts 9 Jan" / "Next lesson …"), with the C2 empty state. `/courses/new` creates a course with its weekly template and generates its lessons (26 weeks, or up to "Last lesson"); `/courses/{id}/edit` edits it and archives it. `/courses/{id}` shows the next and previous lesson, every lesson (re-time, cancel with a reason, reinstate, add a lesson, Extend) and the roster (enrol an existing student with an optional check-in label, change the label, remove). Two write services (`CourseCatalog`, `Roster`), four read models, six form types, three controllers, eleven templates, three stylesheets, the `courses` catalogue and three include slots for #12/#15. No migration, no config change; `src/Courses/Controller/PlaceholderController.php` is deleted.

## Decisions
- **D1** No "weeks" field: 26 weeks or up to "Last lesson" (max 104). Undo: optional `weeks` field into `generateInitial`. **D2** Template edits leave existing lessons alone (the edit page says so). Undo: regenerate future lessons on save. **D3** Course zone = teacher's zone, no field. Undo: zone select with `Timezones::isValid`.
- **D4/P4** Lessons and roster on `course_show`; "All lessons (n)" and every per-row form in `<details>`; no extra GET route. Undo: a lessons page. **D5** `/courses/new` is a page at both widths (C3 side panel → #20).
- **D6** Check-in label unique among a course's active enrolments, case-insensitive, checked in PHP (`mb_strtolower`), no DB constraint. Undo: a functional unique index (needs a schema grant).
- **D8** Archived courses leave the list; their page opens read-only (badge, no forms); no un-archive. **D9** Location prefilled from the latest active course; no live summary line. **D10** Lesson cancel on the course page. **D11/P8** Unknown, foreign and malformed IDs all 404 (UUID requirements + `findOwned` + same-course check).
- **P1/P2** `#[CurrentUser] Teacher` and class-level `#[IsGranted('ROLE_TEACHER')]`; ownership via `findOwned` in a controller helper, not the voter. Undo: `#[IsGranted(TeacherOwnsVoter::ATTRIBUTE, subject: …, statusCode: 404)]`.
- **P3** Token-only actions (archive, extend, reinstate, remove) use one field-less `ConfirmActionType`. **P5** Sub-route POSTs always 303 to `course_show` with a flash; only new/edit re-render with 422. Undo: per-form re-render of `show`. **P6** "Today"/"Starts later" computed per row in the course zone. **P7** Durations 45/60/75/90 (+ the current value).
